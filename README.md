# Íslensk orðskipting fyrir InDesign

Niðurhalssíða fyrir uppsetningarpakka sem setur íslenskar orðskiptireglur inn í Hunspell í Adobe InDesign 2020–2027 á Mac.

- `index.html`: síðan
- `Islensk-ordskipting-InDesign-1.8.pkg`: uppsetning
- `Fjarlaegja-islenska-ordskiptingu.pkg`: fjarlæging
- `vercel.json`: lætur Vercel senda .pkg-skrár sem niðurhal

Orðskiptireglur byggðar á Icelandic Hyphenation Dictionary 2.0 (Kristján Rúnarsson, Stofnun Árna Magnússonar, CC BY 4.0) og verki Baldurs Jónssonar og Magnúsar Gíslasonar (1985).
